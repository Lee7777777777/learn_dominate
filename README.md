# 知路 · 学习地图

一个用 Python 编写的本地学习辅助桌面应用。用知识点、论文、课程和实践模块构建学习网络，记录进度、笔记与参考资料。

## 启动

需要 Python 3.10 或更新版本，并包含 Tkinter（Windows 官方 Python 安装器中的 Tcl/Tk 组件）。无需 pip 安装第三方库。

在 Windows **双击 `start.vbs`**，直接打开图形界面，不显示 PowerShell 或命令行窗口。也可双击 `start.pyw`（需要正确的 Python 文件关联）。原 `start.bat` 已改为转交无控制台入口，但双击批处理本身可能短暂闪过命令行，因此推荐使用 `start.vbs`。

开发调试时仍可在项目目录运行：

```powershell
python app.py
```

原有数据保留在项目的 `data/learning_map.db`，自动显示为「我的第一张地图」，与启动时的工作目录无关。地图目录保存在 `data/learning_map.library.db`，新地图分别保存在 `data/learning_map_maps/`，不会清空旧地图。启动时恢复上次打开的地图。可指定其他地图库的初始数据库：

```powershell
python app.py --db D:\MyLearning\map.db
```

## 使用方法

顶部「＋ 新建地图」创建一张全新的空白地图。通过「学习空间」下拉框切换地图，也可重命名。切换前会提示保存未完成的笔记；同名地图会被阻止。

顶部「画布背景」可切换晴空点阵、暖纸网格和午夜星空，每张地图独立记忆。背景随画布平移缩放，模块采用圆角卡片、状态色和选中边框。空白画布可直接点击「添加第一个模块」。

1. 点击「载入示例地图」体验，或点击「新建模块」创建自己的内容。示例仅能载入空地图。
2. 选择模块，在右侧编辑名称、类型、状态、掌握程度、简介、标签和笔记。点击「保存修改」或按 Ctrl+S。
3. 点击「＋ 前置模块」或「＋ 延伸模块」创建并连接新模块。连接已有模块时，使用顶部「建立关系」。允许同名模块，关系选择器通过 ID 区分。
4. 前置依赖 A → B 表示 A 是 B 的前提；进阶延伸 A → B 表示学完 A 后可以继续探索 B；相关内容不区分方向。程序拒绝自连接、重复关系和循环前置依赖。
5. 拖动节点移动，拖动空白区域或按住右键拖动平移，滚轮缩放。「自动排列」按前置依赖分层；延伸和相关关系不决定学习顺序。
6. 左侧按名称、标签、简介搜索，并按类型、状态筛选。「聚焦当前模块」显示当前模块和直接相邻模块，并与筛选条件叠加。
7. 右侧「模块关系」标签页可查看、删除关系，双击关系跳转到相连模块。

## 保存与备份

- 创建模块、连接、删除、布局和拖动位置立即写入 SQLite。详情和笔记需点击保存；切换模块、关闭窗口及导入导出时，会提示未保存的修改。
- 「导出备份」导出**当前地图**的 JSON，包含笔记、关系和坐标，不受当前筛选影响；不包含地图名称和背景设置，兼容第一版 JSON 文件。
- 「导入地图」校验完整文件后替换当前地图，不是合并，其他地图不受影响。替换前会保存自动备份至初始数据库目录的 `backups/<地图ID>/` 文件夹。校验失败不会改变当前数据。若要作为新地图导入，先新建空白地图再导入。
- 「撤销删除 / 导入」恢复最近一次删除或导入前的**当前地图完整快照**，因此之后的新增和修改也会回退。恢复前再次备份当前地图。最多保留当前地图本次打开的 10 个撤销点，切换地图或关闭后撤销历史不保留。
- 资料区域保存纯文本链接和文件路径，不复制 PDF 等附件。更换电脑时需自行迁移附件。
- 可关闭 APP 后复制整个 `data` 文件夹备份全部地图及背景设置；JSON 导出适合单张地图迁移。不要单独移动地图目录数据库。
- 无控制台入口的错误日志位于 `data/app.log`，启动失败时会弹窗提示。

## 当前范围

这是可运行的桌面 APP，支持多张独立地图；不同地图之间的模块和笔记互不关联。模块类型可区分，但共用一套字段。暂不包含多地图共享模块、云同步、AI、自动复习、富文本编辑或可执行文件打包。地图适合个人中小规模知识网络；大量节点时建议筛选和聚焦查看。

## 验证

```powershell
python -m unittest test_storage test_library test_ui test_launcher -v
```

UI 测试会短暂打开真实 Tk 窗口，需要可用的桌面环境。所有测试都使用临时数据库，不改动学习数据。

文件结构：`app.py` 为界面，`storage.py` 为 SQLite 与图规则，`library.py` 管理多地图，`start.vbs` / `start.pyw` 为无控制台启动入口，`test_*.py` 为测试。
